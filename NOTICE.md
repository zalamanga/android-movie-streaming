# Atribusi source dan aset

Source lokal `MovieStreamingApp-master` mengacu ke proyek berikut pada README aslinya:

- Repository upstream: https://github.com/Nimith-Nimeshana/MovieStreamingApp
- Penulis/account upstream: Nimith-Nimeshana
- Nama aplikasi/package asal: @flix / `com.example.flixproject`

Ekspor ini menjaga identitas UI, warna, layout, dan aset dari source tersebut. Perubahan pada ekspor meliputi konfigurasi build, state ketika Firebase belum dikonfigurasi, pencarian, logout, pembacaan snapshot database, guard data kosong, dan lifecycle player. Ekspor ini tidak mengirim perubahan ke upstream.

Tidak ditemukan berkas LICENSE proyek dalam salinan source lokal. Jangan menafsirkan ekspor ini sebagai pemberian lisensi baru untuk source, branding, screenshot, aset, film, atau data milik upstream. Dependency AndroidX, Firebase, Glide, ExoPlayer, AutoImageSlider, dan CircleImageView tetap mengikuti lisensi masing-masing. Konfigurasi Firebase, akun, database, dan video upstream tidak disertakan.
